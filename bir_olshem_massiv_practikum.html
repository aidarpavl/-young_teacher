Бір өлшемді массивтер (тізімдер) — Python-дағы ең негізгі құрылымдардың бірі. Бұл практикумда біз ЖИ-дің жиі жіберетін қателерін талдап, оларды түзетуді үйренеміз. Академиялық адалдық пен бағдарламалау мәдениетін қалыптастырамыз.

Бір өлшемді массивтер: негізгі әдістер
Негіздер

Құру және индекстеу

arr = [10, 20, 30, 40] print(arr[0]) # 10 print(arr[-1]) # 40 arr[1] = 99 # өзгерту
listindex
Слайсинг

Бөліктерді алу

arr = [1, 2, 3, 4, 5] print(arr[1:4]) # [2, 3, 4] print(arr[:3]) # [1, 2, 3] print(arr[::2]) # [1, 3, 5]
Әдістер

append, insert, remove

a = [10, 20] a.append(30) # [10, 20, 30] a.insert(1, 15) # [10, 15, 20, 30] a.remove(20) # [10, 15, 30]
Итерация

for және enumerate

fruits = ['алма', 'банан'] for i, val in enumerate(fruits): print(i, val) # 0 алма # 1 банан
ЖИ жиі жіберетін қателер (массивтер)
ЖИ қатесіИндекстеу

Қате индекстен тыс шығу

arr = [5, 10, 15] print(arr[3]) # ❌ IndexError
ЖИ: "arr[3] — төртінші элемент" деп ойлайды, бірақ индекстер 0-ден басталады.
Дұрыс: arr[0] = 5, arr[2] = 15. Ең үлкен индекс — len(arr)-1.
ЖИ қатесіСлайсинг

Слайсинг шекарасы

arr = [1, 2, 3, 4] print(arr[1:3]) # [2, 3] ✅ # ЖИ жиі: arr[1:4] = [2,3,4] деп шатасады
ЖИ: "arr[1:3] үш элемент қайтарады" деп қателеседі.
Дұрыс: соңғы индекс кірмейді. arr[1:3] → [2, 3]
ЖИ қатесіӘдістер

remove() қателігі

a = [10, 20, 30, 20] a.remove(20) print(a) # [10, 30, 20]
ЖИ: "remove(20) барлық 20-ларды жояды" деп қате айтады.
Дұрыс: remove() тек бірінші кездескен элементті жояды.
ЖИ қатесіКөшіру

Тізімді меншіктеу

a = [1, 2, 3] b = a # ❗️ сілтеме b.append(4) print(a) # [1, 2, 3, 4]
ЖИ: "b = a жаңа тізім жасайды" дейді.
Дұрыс: көшіру үшін b = a.copy() немесе list(a).
ЖИ қатесіЦикл

for i in arr: arr.remove()

arr = [1, 2, 2, 3] for x in arr: if x == 2: arr.remove(x) # ❌ қауіпті
ЖИ: "барлық 2-лерді жояды" деп уәде береді, бірақ индекстер ығысады.
Дұрыс: arr = [x for x in arr if x != 2]
ЖИ қатесіСорттау

sort() vs sorted()

a = [3, 1, 2] b = a.sort() print(b) # None
ЖИ: "b — сұрыпталған тізім" дейді.
Дұрыс: sort() тізімді өзгертеді және None қайтарады. b = sorted(a) қолданыңыз.
