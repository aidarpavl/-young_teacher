Можно составить расписание автоматически (учитывается учитель кружка, ученики и нагрузка по дням) или расставить кружки вручную в ячейках. Красным подсвечиваются совпадения учителя или учеников в одно и то же время.

Журнал создаётся по каждому кружку. Если в кружок записаны ученики, показываются они, иначе весь список. Отметки сохраняются в браузере; в Excel — лист на каждый кружок.

Настройка записи в Лист5 (один раз)

Страница не может сама писать в Google Таблицу без разрешения. Чтобы кнопка «Сохранить в Лист5» писала напрямую:

  1. Откройте таблицу → Расширения → Apps Script и вставьте код ниже.
  2. Развернуть → Новое развёртывание → тип «Веб-приложение», доступ «Все». Скопируйте URL (оканчивается на /exec).
  3. Вставьте URL в поле ниже и нажмите «Запомнить».
const SHEET_NAME = 'Лист5';
function doPost(e) {
  const rows = JSON.parse(e.postData.contents).rows;
  const sh = SpreadsheetApp.getActive().getSheetByName(SHEET_NAME);
  sh.clearContents();
  if (rows.length) sh.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
  return ContentService.createTextOutput('ok');
}
function doGet() {
  const sh = SpreadsheetApp.getActive().getSheetByName(SHEET_NAME);
  return ContentService.createTextOutput(JSON.stringify(sh.getDataRange().getValues()))
    .setMimeType(ContentService.MimeType.JSON);
}

Без этой настройки кнопка «Сохранить в Лист5» копирует расписание в буфер обмена — достаточно вставить его (Ctrl+V) в ячейку A1 на Лист5. Чтение Лист5 работает, если таблица открыта по ссылке для просмотра.
