PyGame — Python-да 2D ойындар мен графикалық қосымшалар жасауға арналған танымал кітапхана. Бұл практикумда біз PyGame-ның негізгі құрылымдарын, ойын циклін, спрайттарды, дыбысты және оқиғаларды өңдеуді үйренеміз. ЖИ-дің осы тақырыпта жиі жіберетін қателерін талдап, оларды түзетуді меңгереміз.

PyGame: негізгі құрылымдар
Негіздер

Ойын терезесін құру

import pygame pygame.init() screen = pygame.display.set_mode((800, 600)) pygame.display.set_caption("Менің ойыным") running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False pygame.display.flip() pygame.quit()

ЖИ қатесіЦикл

pygame.quit() орны

while True: for event in pygame.event.get(): if event.type == pygame.QUIT: pygame.quit() # ❌ цикл жалғасады pygame.display.flip()
ЖИ: «pygame.quit() шақырса, цикл автоматты тоқтайды» деп ойлайды. Шын мәнінде, цикл жалғасады және бағдарлама қате береді.
Дұрыс: running = False айнымалысын қолданып, циклды тоқтату керек.
ЖИ қатесіFPS

Clock.tick() ұмыту

while running: # ... ойын логикасы ... pygame.display.flip() # ❌ clock.tick(60) жоқ
ЖИ: «ойын циклі FPS-ке тәуелсіз жұмыс істейді» дейді. Шын мәнінде, цикл өте жылдам айналады, CPU 100% жүктеледі.
Дұрыс: clock = pygame.time.Clock(); clock.tick(60) — 60 FPS шектеуі.
ЖИ қатесіBlit

blit() дұрыс емес аргументтер

screen.blit(player_img, (x, y)) # ✅ # ЖИ кейде: screen.blit(player_img, player_rect) # ✅ rect те болады screen.blit((x, y), player_img) # ❌ реті қате
ЖИ: «blit(x, y) координаттарын бірінші қабылдайды» деп шатастырады.
Дұрыс: surface.blit(image, (x, y)) немесе surface.blit(image, rect).
ЖИ қатесіСпрайт

Спрайттар тобын жаңарту

all_sprites = pygame.sprite.Group() all_sprites.add(player) # ... all_sprites.draw(screen) # ✅ all_sprites.update() # ✅
ЖИ: «спрайттар өздігінен жаңарады» дейді.
Дұрыс: әр кадрда all_sprites.update() және all_sprites.draw(screen) шақыру керек.
ЖИ қатесіRect

Rect координаттары

rect = pygame.Rect(100, 100, 50, 50) rect.x += 5 # ✅ rect.center = (400, 300) # ✅ # ЖИ кейде: rect.x += 5, 0 # ❌
ЖИ: «rect.x-ке кортеж қосуға болады» дейді.
Дұрыс: rect.x және rect.y жеке бүтін сандар. rect.move_ip(dx, dy) — қозғалу үшін.
ЖИ қатесіСурет

convert() / convert_alpha()

img = pygame.image.load("player.png").convert_alpha() # ✅ мөлдірлік үшін # ❌ convert() мөлдірлікті жоғалтады
ЖИ: «convert() және convert_alpha() бірдей» дейді.
Дұрыс: PNG мөлдірлігі үшін convert_alpha(), басқа суреттер үшін convert() — жылдамдықты арттырады.
