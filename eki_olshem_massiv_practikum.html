Екі өлшемді массивтер (матрицалар, кестелер) — Python-дағы тізімдердің ішіндегі тізімдер арқылы жасалады. Бұл практикумда біз ЖИ-дің матрицалармен жұмыс істегенде жиі жіберетін қателерін талдап, оларды түзетуді үйренеміз. Академиялық адалдық пен бағдарламалау мәдениетін қалыптастырамыз.

Екі өлшемді массивтер: негізгі әдістер
Негіздер

Құру және индекстеу

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]] print(matrix[0][1]) # 2 print(matrix[2][0]) # 7 matrix[1][2] = 99 # өзгерту
list of lists[i][j]
Өлшемдер

Жолдар мен бағандар саны

m = [[1, 2, 3], [4, 5, 6]] rows = len(m) # 2 cols = len(m[0]) # 3
Айналу / басып шығару

Кірістірілген цикл

for row in m: for x in row: print(x, end=' ') print()
Генератор

Матрицаны comprehension-мен құру

n, k = 3, 4 m = [[0]*k for _ in range(n)] # 3 жол, 4 баған
ЖИ жиі жіберетін қателер (екі өлшемді массивтер)
ЖИ қатесіКөшіру

Бірдей жолдарға сілтеме

m = [[0]*3] * 2 m[0][0] = 5 print(m) # [[5,0,0],[5,0,0]] ❌
ЖИ: «екі тәуелсіз жол жасалды» деп ойлайды, бірақ [[0]*3]*2 бір ғана тізімге сілтеме жасайды.
Дұрыс: m = [[0]*3 for _ in range(2)]
ЖИ қатесіИндекстеу

Жол мен бағанды шатастыру

m = [[1, 2, 3], [4, 5, 6]] print(m[1][2]) # 6 ✅ # ЖИ жиі m[2][1] деп қателеседі
ЖИ: «бірінші индекс — баған» деп қате түсінеді.
Дұрыс: m[жол][баған]. m[1][2] → 2-жол, 3-баған = 6
ЖИ қатесіТранспозиция

zip арқылы транспозиция

m = [[1, 2], [3, 4], [5, 6]] t = list(zip(*m)) print(t) # [(1,3,5),(2,4,6)]
ЖИ: «zip бағандарды емес, жолдарды біріктіреді» деп қателеседі.
Дұрыс: zip(*m) бағандарды топтайды — нәтиже кортеждер тізімі.
ЖИ қатесіСлайсинг

Жолды көшіру

m = [[1, 2, 3], [4, 5, 6]] row = m[0] # ❗️ сілтеме row[0] = 99 print(m[0]) # [99, 2, 3]
ЖИ: «row = m[0] жолды көшіреді» дейді.
Дұрыс: row = m[0].copy() немесе list(m[0])
ЖИ қатесіІздеу

2D массивте in қолдану

m = [[1, 2], [3, 4]] print(3 in m) # False ❗️
ЖИ: «3 матрицада бар, сондықтан True» дейді.
Дұрыс: in тек жоғарғы деңгейді тексереді. Ішкі элемент үшін: any(3 in row for row in m)
ЖИ қатесіСорттау

Жолдарды сорттау

m = [[3, 2], [1, 4]] m.sort() # жолдар бойынша print(m) # [[1,4],[3,2]]
ЖИ: «барлық сандарды сұрыптайды» дейді.
Дұрыс: sort() жолдарды (ішкі тізімдерді) салыстырады. Барлық элементтер үшін: sorted(x for row in m for x in row)

Сарапшы рөліне ен: ЖИ қатесін тап

📌 Тапсырма: Берілген кодтың нәтижесін болжаңыз және ЖИ қатесін табыңыз.

ChatGPT «шешімі»:
m = [[1, 2], [3, 4]]; m2 = m.copy(); m2[0][0] = 99; print(m)
"Нәтиже: [[1, 2], [3, 4]] — m өзгермейді, себебі copy() терең көшіру жасайды"

Сіздің диагнозыңыз:

Дұрыс жауап: m.copy() — таяз көшіру. m2[0] мен m[0] бір тізімге сілтейді, сондықтан m → [[99, 2], [3, 4]]. Терең көшіру үшін copy.deepcopy() керек.
