🔄 Бір өлшемді массивтердің элементтерін ауыстыру

Python тілінде · ЖИ-аудит · Сыни ойлау

Бір өлшемді массивтердің элементтерін ауыстыру — бағдарламалаудағы маңызды дағды. Бұл практикумда біз Python-да тізім элементтерін орнын ауыстыру, қайта реттеу, бөлу және біріктіру әдістерін үйренеміз. ЖИ-дің осы тақырыпта жиі жіберетін қателерін талдап, оларды түзетуді меңгереміз.

Элементтерді ауыстыру: негізгі әдістер
Негіздер

Екі элементті ауыстыру

a = [10, 20, 30, 40] a[0], a[3] = a[3], a[0] print(a) # [40, 20, 30, 10]
swaptuple
Блоктар

Бөліктерді орын ауыстыру

a = [1, 2, 3, 4, 5] a[:2], a[3:] = a[3:], a[:2] print(a) # [4, 5, 3, 1, 2]
Айналдыру

Массивті кері айналдыру

a = [1, 2, 3, 4] a.reverse() print(a) # [4, 3, 2, 1] # немесе a = a[::-1]
Жылжыту

Циклдік жылжыту (rotate)

a = [1, 2, 3, 4, 5] k = 2 a = a[-k:] + a[:-k] print(a) # [4, 5, 1, 2, 3]
ЖИ жиі жіберетін қателер (ауыстыру)
ЖИ қатесіSwap

Уақытша айнымалысыз қате swap

a = [5, 10] a[0] = a[1] # ❌ 10 a[1] = a[0] # ❌ 10 print(a) # [10, 10]
ЖИ: «a[0] = a[1]; a[1] = a[0] дұрыс ауыстырады» деп ойлайды, бірақ бірінші амалдан кейін a[0] мәні жоғалады.
Дұрыс: a[0], a[1] = a[1], a[0] немесе temp = a[0]; a[0] = a[1]; a[1] = temp
ЖИ қатесіСлайсинг

Слайсинг шекарасын шатастыру

a = [1, 2, 3, 4, 5] a[:2], a[2:] = a[2:], a[:2] print(a) # [3, 4, 5, 1, 2] ✅
ЖИ кейде a[:2] екі емес, үш элемент алады деп қателеседі.
Дұрыс: a[:2] — индекстер 0,1 (2 кірмейді).
ЖИ қатесіreverse

reverse() қайтаратын мән

a = [1, 2, 3] b = a.reverse() print(b) # None ❌
ЖИ: «b — кері айналдырылған тізім» дейді.
Дұрыс: reverse() тізімді орнында өзгертеді, None қайтарады. Көшіру үшін: b = a[::-1] немесе b = list(reversed(a)).
ЖИ қатесіЖылжыту

Циклдік жылжыту

a = [1, 2, 3, 4, 5] k = 2 a = a[k:] + a[:k] print(a) # [3, 4, 5, 1, 2]
ЖИ: «оңға жылжыту a[-k:] + a[:-k]» деп шатастырады.
Дұрыс: солға жылжыту — a[k:] + a[:k]; оңға жылжыту — a[-k:] + a[:-k].
ЖИ қатесіКөшіру

Сілтеме бойынша ауыстыру

a = [1, 2, 3] b = a # ❗️ сілтеме b[0], b[2] = b[2], b[0] print(a) # [3, 2, 1]
ЖИ: «b — тәуелсіз көшірме» дейді.
Дұрыс: b = a.copy() немесе b = a[:] қолданыңыз, әйтпесе a да өзгереді.
ЖИ қатесіСорттау

sort() кезіндегі ауыстыру

a = [3, 1, 2] b = a.sort() print(a) # [1, 2, 3] print(b) # None
ЖИ: «sort() сұрыпталған тізімді қайтарады» дейді.
Дұрыс: sort() орнында сұрыптайды. Жаңа тізім үшін: b = sorted(a).

Сіздің диагнозыңыз:
